# عرض لسن السينمائي

عرض تقديمي سينمائي في ملف HTML واحد، يعمل في أي متصفح دون تثبيت.

## التشغيل
افتح `index.html` في المتصفح، ثم اضغط «ابدأ العرض».

| الإجراء | المفتاح |
|---|---|
| الشريحة التالية | ← أو المسافة أو النقر على النصف الأيسر |
| الشريحة السابقة | → أو النقر على النصف الأيمن |
| ملء الشاشة | F |
| الجوال | السحب يمينًا ويسارًا |

## التعديل
- كل شريحة عنصر `<section class="slide">`. انسخ واحدة وغيّر النص.
- `data-bg` يختار الخلفية (1–5)، و`data-light` يحدد موضع البقعة الضوئية (x,y بالنسبة المئوية).
- أضف الصنف `split` لأي عنوان ليظهر كلمة بكلمة. التقسيم بالكلمة لا بالحرف حتى تبقى الحروف العربية متصلة.
- `--d` يؤخّر ظهور العنصر بالملّي ثانية.
- الألوان في `:root` أعلى الملف (`--gold` و`--teal`).
